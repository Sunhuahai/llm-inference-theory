# 开放研究问题与最小可证伪实验

这些问题决定后续研究投入，不代表已经解决。理论、模型和自主优化围绕同一个小案例交叉推进，参见 [路线图](../../docs/roadmap.md)。

| 问题 | 可检验假设 | 最小对照与失败信号 |
| --- | --- | --- |
| R1 瓶颈可辨识性 | 少量区分性观测足以缩小竞争解释 | 相同表面利用率、不同实际依赖的案例；若诊断频繁混淆，应增加观测或承认不可辨识 |
| R2 干预收益预测 | 资源与执行模型能预测候选的方向和排序 | 独立校准后留出候选；基线吻合但候选排序错误，说明模型未识别机制 |
| R3 多策略耦合 | 交互与瓶颈迁移比独立收益相乘更能解释组合 | baseline/A/B/AB，跨两类负载；预测交互符号不稳定时修订模型 |
| R4 理论引导搜索 | 同信息权限与预算下，显式理论能改善搜索效率 | 普通 Agent、同 profiler、理论工具消融；计入建模成本后无提升即不支持假设 |
| R5 信息获取价值 | 一次有针对性的测量比直接实现更有价值 | 相同预算下先测量/直接实现；看达标成本和错误方向投入，而非只看拟合精度 |
| R6 经验迁移 | 条件化记忆能减少重复失败且不屏蔽新机会 | 无记忆/无条件记忆/适用域记忆；留出版本与 shape，统计误剪枝和校准成本 |
| R7 多层优化 | 全局目标选择比只追求最快 kernel 更有效 | 相同任务的局部优先/全局收益优先；检查服务 goodput、内存与尾部回归 |
| R8 动态策略 | 自适应决策的收益能超过监测与切换成本 | 固定配置/负载自适应，同一时序 trace；纳入切换损耗及短期不稳定 |

## 共同的证据要求

假设在看结果前登记；预测与结果分开；失败、超时、不可行与不显著都记录。只有开发集成绩不够，最终方法和候选应在未参与选择的条件下复测。没有稳健证据时标为 inconclusive，不以合成演示替代真实评价。

单纯“最佳加速比更高”不能证明理论的作用：还要排除更大预算、更多工具、额外 profiling、评价泄漏、弱基线和改变质量等解释。对于有限动作空间，最优值只有在完整评价或可证明求解后才已知；未知时不报告声称相对全局最优的精确 regret。
