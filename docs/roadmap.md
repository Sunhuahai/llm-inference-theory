# Research roadmap

## Phase I — 统一理论体系（当前）
完善符号、资源需求、依赖图与服务边界；梳理已证明关系和近似模型。交付理论章节、统一图谱及可证伪命题。

## Phase II — 性能预测
形成可计算资源账本和算子级预测接口；使用微基准校准；区分资源下界与实测预测误差。

## Phase III — 优化耦合
建立跨负载的瓶颈区域与交互模型，预测局部优化后的瓶颈迁移，并验证组合收益。

## Phase IV — 自主优化
以理论缩小搜索空间，采用独立控制器和评估器，比较同预算传统搜索与 Agent 搜索。只有经过独立正确性与服务级测量的候选才被接受。

阶段可以交叉迭代。当前没有通用自主优化器或新的 GPU 实测结果。
