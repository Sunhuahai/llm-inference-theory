# 模型校准、不确定性与适用范围

> 状态：研究方法与 `derived` 关系，2026-11-25。未使用合成输入伪造真实置信区间。

## 1. 校准不是把基线乘回原值

假设 $\widehat T(x;\theta)$ 用参数 $\theta$ 预测工作点 $x$。仅使 $\widehat T(x_0)=T_0$ 不代表理解了瓶颈，很多错误模型也能拟合一个点。模型必须在未参与拟合的工作点上预测时间，尤其要预测**干预后的变化**。

建议分三类记录：校准样本确定参数；开发样本选择模型/特征；最终留出样本评估冻结方案。样本少时可使用按环境或工作负载分组的交叉验证，但最终报告要披露选择次数，不能把反复看过的集合继续称为独立测试。

## 2. 三类不确定性

| 来源 | 例子 | 合适处理 |
| --- | --- | --- |
| 运行噪声 | 温度、时钟、系统背景活动、测量扰动 | 配对交错重复、独立运行或相关块重采样 |
| 参数不确定 | 有效带宽估计样本少 | 记录参数估计与协方差；检查可辨识性 |
| 结构/分布外误差 | 漏了调度等待、换后端、从小 batch 外推 | 留出验证、分段建模、拒绝高置信度外推 |

更多同一条件重复可以减少运行噪声估计的误差，但不会自动修复遗漏机制。Profiler 的采集还会改变执行行为，应按 [Nsight Compute 文档][profile]区分正式 benchmark 与诊断采样。

## 3. 可辨识性与误差指标

若模型的局部雅可比 $J_{ij}=\partial\widehat T(x_i;\theta)/\partial\theta_j$ 列近似线性相关，不同参数组合可能产生几乎相同预测。应增加能够区分机制的工作点，或减少参数；不能用一个复杂拟合器掩盖缺少观测。

在 $T_i>0$ 时，报告有符号相对误差与绝对相对误差：

$$
e_i=\frac{\widehat T_i-T_i}{T_i},\qquad |e_i|.
$$

例如合成预测 12 ms、观测输入 10 ms，$e=0.2$。这说明高估 20%，不代表方差或置信度。还应按 shape、长度、后端、负载区间分组；不同组的正负误差不能相互抵消后声称准确。

对优化决策，额外检查 $\widehat\Delta=T_0^{\rm pred}-T_a^{\rm pred}$ 与配对实际差值的误差、正负方向是否一致、候选排名是否稳定。模型更准确拟合绝对时间，却更差地区分候选，也是可能的。

## 4. 区间怎样得到

没有数据时，可以给出保守/中心/乐观**情景区间**，说明参数范围的依据。这不具备“95% 概率”含义。

若参数估计具有可支持的协方差 $\Sigma$，且 $g(\theta)$ 在局部可微，可作一阶近似：

$$
\operatorname{Var}[g(\widehat\theta)]\approx\nabla g^\top\Sigma\nabla g.
$$

关键路径的 `max` 在瓶颈切换处不可微，简单一阶近似可能失效；可使用保留共享参数相关性的抽样传播，同时报告这种传播没有覆盖结构误差。基线与候选应使用同一环境参数样本计算差值，不能把高度相关的输入当独立变量。

若用 bootstrap，独立单位应匹配实验设计：同批次请求、同会话和同设备状态可能相关，不能直接按每个 token 独立重采样。搜索过程试过大量候选时，最终胜者需要新的确认样本，避免把选择噪声作为收益。

## 5. 分布外与拒绝预测

记录 `valid_domain`：模型架构、设备/软件版本、dtype、shape 区间、缓存和并发范围。跨后端、跨 GPU 或跨模型必须重新检查，不能只因名称相近沿用速率。输出可取：域内预测、谨慎外推、仅下界、无法识别。`unknown` 是有用的研究结果，零值不是未知的替代。

给 Agent 的下一步建议应与误差来源对应：带宽参数不确定就补微基准；图结构不明就补时间线；负载分布不明就补 trace。只有在有数据支持的模型上，概率收益/成本排序才有概率意义。
