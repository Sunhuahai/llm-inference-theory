## 应当输出什么

有用的优化结论应包含目标指标、适用域、baseline、可消除成本、新增代价、条件预测及失效条件。只给一个加速倍数，无法判断是否能迁移；只列技术名称，也无法判断当前实现是否已经覆盖。

理论可以给出严格边界、条件推导或近似预测。这三种结果使用不同证据：严格边界需要口径匹配的需求和能力上界；近似预测需要独立校准；成功结论需要真实、正确且可复现的对照测量。

下一步的研究重点是预测候选排序、条件收益与瓶颈迁移能否在留出负载中成立。它与[性能模型](../../models/README.md)、[Agent 自主优化](../../optimizer/README.md)及[实验平台](../../experiments/README.md)并行推进。
