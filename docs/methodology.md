# Research methodology

理论研究先定义任务、可控变量、约束、工作负载和观测量，再建立资源账本与执行依赖模型。必须区分严格恒等式/下界、条件性近似、文献报告、合成仿真和实际测量。

预测应给出适用范围、不确定性或误差来源，并定义能够否定假设的实验。实验使用固定模型、精度、任务语义、资源预算、代表性负载与独立正确性检查；比较端到端指标而非孤立 microbenchmark。没有实际测量时明确标注。

文献研究优先官方源码、论文与可复现数据，记录版本和日期。候选搜索必须保留负结果、评估成本与独立 oracle，防止评价失真。[Benchmark 协议](benchmark-protocol.md)为既有测量参考，针对新场景可增补而非更改历史记录。
